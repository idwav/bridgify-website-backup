Bridgify · Design system

Bridgify Design System

The reference for building bridgify.io. Every colour, type style and spacing value the site uses is named here once, with its value on desktop, tablet and phone. The live site is the reference for behaviour and motion; where the site and this guide differ, this guide wins.

Every value comes from tokens.json. Import it, or use tokens.css, instead of copying values from the pages.

Breakpoints and grid

Three layouts. Every section's content starts and ends on one line, the page margin; no section has its own side padding or max width. On large screens the content stops at 1560px and is centred.

Site rules

RuleValueWhat it means
rule-illustration-text-min10pxText inside illustrations (phone screens, diagrams, windows) scales with the art but is never smaller than 10px as seen. If it does not fit, shorten the illustration or show part of it.
rule-long-demoallowedOwner decision: a demo may be taller than the phone screen, as long as it scrolls with the page and never locks it. (Replaces MOBILE-RULES L2, the 85% limit.)
rule-motionas-desktopPhones play the same animations as desktop, starting when they come into view. Respect prefers-reduced-motion everywhere.
rule-pinmin-width 901px and min-height 701pxA section pins on scroll only on screens at least 901px wide and 701px tall. Smaller screens get the phone behaviour.
