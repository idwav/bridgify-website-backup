Bridgify · Design system

Bridgify Design System

The reference for building bridgify.io. Every colour, type style and spacing value the site uses is named here once, with its value on desktop, tablet and phone. The live site is the reference for behaviour and motion; where the site and this guide differ, this guide wins.

Every value comes from tokens.json. Import it, or use tokens.css, instead of copying values from the pages.

Breakpoints and grid

Three layouts. Every section's content starts and ends on one line, the page margin; no section has its own side padding or max width. On large screens the content stops at 1560px and is centred.

Typography

Two families and 13 roles. Pick the role by what the text does, not by its HTML tag: a title inside a phone mock-up is part of the illustration, not a section heading.

Display · headings and numbersChillaxLight 300 for headings. Regular 400 for titles on phones. Medium 500 for large numbers only.
Text · everything elseSofia SansVariable. 400 text, 550 buttons and labels, 600 step numbers.
Code windows onlyui-monospaceThe system monospace. No Arial, no Georgia anywhere.

Text inside illustrations

Text inside illustrations (phone screens, diagrams, windows) scales with the art but is never smaller than 10px as seen. If it does not fit, shorten the illustration or show part of it.
