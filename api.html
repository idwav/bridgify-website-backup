Frequently asked questions
How does the Bridgify Experiences API work?
You integrate once. Bridgify connects to multiple global marketplaces, aggregators and suppliers, normalizes their content into one schema and returns search, availability, pricing and booking through a single API. Your team builds the interface; Bridgify manages the supply behind it.
What is an API for travel?
A travel API lets one system request travel content and bookings from another. A bank app, for example, can show live tours and take bookings without holding any supply itself. Bridgify's Experiences API covers tours, attractions, activities and events.
What is the difference between a travel API and a booking API?
"Travel API" is the broad term for any API that serves travel content, such as flights, hotels or experiences. A booking API is the part that confirms and manages reservations. The Experiences API does both for experiences: discovery content plus booking and cancellation.
How do I choose the best API for activity inventory?
Start with coverage: how many sources, destinations and categories are behind it. Then check real-time availability, content quality, and booking and cancellation handling. A multi-source API gives you more coverage and less dependence on one supplier.
Why not connect to Viator or GetYourGuide directly?
Going direct gives you one catalog on one supplier's terms. Viator and GetYourGuide are strong networks, and both are inside the Bridgify catalog. Bridgify gives you them plus Tiqets, Musement, Klook and others through one integration and one schema. If you want the deepest relationship with one supplier, go direct. If you want coverage and flexibility, that's what we do.
Does Bridgify include the Viator API?
Yes. The Experiences API includes Viator, plus GetYourGuide, Tiqets, Klook, Musement and direct suppliers, through one integration and one normalized schema, instead of building and maintaining each API separately.
What is an attraction ticket API?
An API that lets a platform sell entry tickets to museums, landmarks, theme parks and other venues: availability, prices, booking and the ticket itself. The Experiences API covers attraction tickets alongside tours, activities and events, from multiple suppliers.
What's the difference between a things-to-do API and a tours and activities API?
The terms overlap. "Things to do" is the traveler-facing term and usually covers attractions, tours, activities and events. "Tours and activities" is the supplier-side term. The Experiences API covers the full range.
Does the API include event tickets?
Yes. Live events, including concerts, sports and shows, sit alongside tours, attractions and activities.
How long does integration take?
It depends on how much of the journey you build yourself. Your team integrates one API instead of one per supplier, and our team supports you through it. If you need to launch without development, the White-Label Marketplace goes live in 3 days.
